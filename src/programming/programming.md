# Programming Guide

This section provides an introductory guide to various concepts involved in FRC programming
and should give you all the information you need to get started writing code on this team,
as well as some resources.

Most information related to robot code and programming can be found on the [WPILib Official Documentation](https://docs.wpilib.org),
so if you have additional questions, you should look there.
