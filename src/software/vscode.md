# Visual Studio Code

We may use two different versions of Visual Studio Code:
1. WPILib's custom build of VS Code with FRC-related features.
2. The regular version of VS Code, for use with non-robot code projects

## Where to download/update
WPILib's custom build: [With the rest of WPILib](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html)

Regular version: [https://code.visualstudio.com/download](https://code.visualstudio.com/download)

The regular version of VS Code will update automatically. WPILib's build will update
when you install new versions of WPILib.

For more information on installing and updating WPILib and its tools see
[the WPILib page](wpilib.md)

## Description
VS Code is a text editor with support for extensions and utilities to run and debug code.

## How to use
1. Building and deploying robot code: See [the guide on robot code deployment](../programming/wpilib.md#how-do-we-build-and-deploy-robot-code)
2. Open file: Go to "File" on the top bar and click "Open Folder", then select the folder.
3. Install extensions: Go to the extensions page on the sidebar and search for the desired extensions.
4. Creating WPILib projects: See [WPILib's docs](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-4/creating-test-drivetrain-program-cpp-java-python.html)
