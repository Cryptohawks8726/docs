# GitHub Desktop

## Where to download/update
Download: https://desktop.github.com/download/
Downloaded as a windows installer.
GitHub desktop will update automatically once installed.

## Description
GitHub desktop is an application to run commit git tasks like pushing to/pulling
from a repository, cloning repositories, and managing cloned repositories. It is 
an alternative to the Git CLI.

## How to use
For more information on using GitHub Desktop see the 
[Git and GitHub section of the docs](../git/git.md).

## Official Resources
Documentation: https://docs.github.com/en/desktop
